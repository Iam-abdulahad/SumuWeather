# 🌤️ Real-Time Weather Dashboard

Welcome to the **Real-Time Weather Dashboard**, a sleek and responsive weather app built with **React**, **Tailwind CSS**, and the **Open-Meteo API**. This application dynamically fetches the user's current location, displays weather information, and updates the browser title with real-time data.  

🌐 **Live Demo**: [strong-basbousa-e70b9a.netlify.app](https://strong-basbousa-e70b9a.netlify.app/)

---

## ✨ Features

- 📍 Detects your **current location** using the browser's geolocation API
- ☀️ Fetches real-time **weather data** from [Open-Meteo API](https://open-meteo.com/)
- 🏙️ Uses **reverse geocoding** to get your **city name**
- 🕐 Updates weather information **dynamically**
- 🖥️ Clean and responsive **UI with Tailwind CSS**
- 🧠 Built using **React Hooks** and modern JavaScript
- 🧭 Real-time weather info in **browser tab title**

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS
- **APIs**:
  - [Open-Meteo API](https://open-meteo.com/)
  - [OpenCage Geocoder](https://opencagedata.com/) *(optional for reverse geocoding)*
- **Deployment**: Netlify
